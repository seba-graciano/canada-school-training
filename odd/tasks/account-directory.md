# Registered account directory and deletion
Add the searchable real account directory and per-account deletion to the existing redesigned screen. Branch: `feat/figma-redesign`; baseline: `416c880`.
Delivery: local work units only; deployment/publication require an explicitly selected destination/session. Verification: Node handler tests, PGlite migration/RLS tests, browser regressions, build/lint and independent security-sensitive verification.

## Specs

- S1: "En el \"Administracion de cuentas\" quiero poder ver las cuentas registradas actualmente con su rol." Read actual Auth identities and their protected profile roles. Keep the existing creation workflow; show unassigned roles explicitly rather than inventing a role.
- S2: "Deberia mostrar, en una tabla de busqueda, el correo, con el rol al lado y 3 puntos para poder interactuar con dicha cuenta, por si es necesario eliminarla." Provide email search, stable pagination, email/role columns, an accessible three-dot action menu and a confirmation before account deletion. Use the existing visual system and mobile layout.
- S3: Implementation invariants for S1/S2: only current administrators can list/delete accounts; service credentials remain server-side. Delete the Auth identity/profile, preserving tutor/student/installment/payment records. Block self-deletion and serialize last-administrator protection. Existing tokens from deleted profiles must not retain application RLS/RPC privileges. Expose no unrelated sensitive Auth metadata.
