- S3 (template, FUN §5, R-02): .xlsx with sheets "Inscripciones" and "Instrucciones". One row per student. Columns: DNI alumno*, Nombre alumno*, Apellido alumno*, Nivel*, Curso*, Arancel mensual*, DNI tutor*, Nombre tutor*, Apellido tutor*, Email tutor, Teléfono tutor. "En la plantilla, Nivel y Curso tienen listas desplegables".
- S4 (cell rules, FUN §5): DNI "7 u 8 dígitos. Se aceptan puntos y espacios, que se quitan." Names: "Se quitan espacios sobrantes." Nivel: "Inicial, Primario o Secundario. No importan mayúsculas ni tildes." Curso must belong to nivel: Inicial → Inicial; Primario → 1º..6º Primaria; Secundario → 1º..6º Secundaria. Arancel: "Pesos, mayor a cero, hasta dos decimales." Email optional: "Si viene, tiene que ser válido. Se guarda en minúsculas." Teléfono: "Texto libre. Puede empezar con +."
- S5 (normalization, R-03, R-04): "3º Primaria, 3o primaria y 3 PRIMARIA se guardan como 3º Primaria." "El arancel puede venir como número de Excel (185000) o como texto con formato argentino (185.000,50). En el formato argentino el punto separa miles y la coma separa decimales." Money travels and is stored as integer cents; never through a float.
- S6 (identity and upsert, R-05, R-06): "Un alumno se identifica por su DNI y un tutor por el suyo. No se usan nombres para identificar a nadie." "Si el DNI del alumno no existe, se crea. Si existe, se actualizan nombre, apellido, nivel, curso, arancel y tutor. Lo mismo para el tutor: si existe, se actualizan sus datos."
- S7 (family, R-07): "Todas las filas con el mismo DNI de tutor quedan bajo el mismo tutor. Si ese DNI tiene nombre, apellido o email distintos en dos filas, es un error (E15): el sistema no adivina cuál es el correcto."
- S8 (atomicity, R-08 + client decision): "O se guardan todas las filas, o no se guarda ninguna." "no se permite importar "solo las filas buenas". Si hay una fila con error, no se importa nada."
- S9 (idempotency, R-09): "Importar dos veces el mismo archivo deja la base igual que importarlo una vez." Same file already imported → preview shows exactly: "Este archivo ya fue importado el {fecha} por {usuario}. Si lo confirmás de nuevo no se va a duplicar nada."
- S10 (order, empty rows, limits, formulas: R-10..R-13): rows processed in sheet order (sibling discount depends on insertion order). "Una fila sin ningún dato se ignora y se informa como "Ignorada"." "Solo archivos .xlsx, de hasta 2 MB y 2.000 filas." "Los campos de nombre y apellido no pueden empezar con =, +, - ni @ (E17).
